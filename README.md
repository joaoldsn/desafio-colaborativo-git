## Sobre o projeto

O **Desafio Colaborativo Git** é um projeto desenvolvido em **Python** com o objetivo de colocar em prática conceitos de **controle de versão e desenvolvimento colaborativo** utilizando Git e GitHub.

O projeto possui funcionalidades relacionadas a **jogadores, batalhas e um sistema de cartas**, permitindo que diferentes partes do desenvolvimento sejam trabalhadas de forma colaborativa.

> O principal objetivo deste projeto é praticar o fluxo de desenvolvimento em equipe utilizando Git e GitHub.

---

## Funcionalidades

* Gerenciamento de jogadores
* Sistema de batalhas
* Sistema de cartas
* Desenvolvimento utilizando Python
* Controle de versão com Git
* Desenvolvimento colaborativo através do GitHub

## Como executar

### Pré-requisitos

Antes de começar, você precisa ter o **Python** instalado em sua máquina.

Você pode verificar a instalação executando:

```bash
python --version
```

ou:

```bash
python3 --version
```

### 1. Clone o repositório

```bash
git clone https://github.com/joaoldsn/desafio-colaborativo-git.git
```

### 2. Entre na pasta

```bash
cd desafio-colaborativo-git
```

### 3. Execute o projeto

```bash
python main.py
```

Caso seu sistema utilize `python3`:

```bash
python3 main.py
```
